# 雅思学习计划

目标：寒假前的1月达到雅思总分7.0。考试形式为学术类机考，具体考试日期待定。

半年前参考成绩：听力7、阅读7、口语6、写作5.5。先从日常练习恢复状态。

## 每日时间

| 模块 | 时间或数量 | 任务 |
| --- | --- | --- |
| 单词 | 150–200词，新学与复习合计 | 不背单词《雅思词汇真经》；从当天词里选10个练拼写 |
| 口语 | 40分钟 | 语料10分钟、影子跟读20分钟、回答10分钟 |
| 写作 | 25分钟 | 小作文、大作文、改错轮换 |
| 听力 | 30分钟 | 一小节或旧题订正 |
| 阅读 | 35分钟 | 雅思专项；每周两次换成外刊精读 |

听阅写合计90分钟，另安排单词和口语。未完成的订正放到下次同科时段，后续新题顺延。

## 每日协作

打开每日聊天，提供仓库链接和最近一条学习记录。聊天按计划给出材料、步骤和完成标准，练习后保存原答案、订正与下次任务。单词进度手动发送。

个人记录保存在本地或Obsidian；仓库保存计划、资料入口、协作说明与空白模板。
