# 雅思学习资料与协作

目标：寒假前的1月达到雅思总分7.0。

## 从这里开始

- [资料目录](RESOURCES.md)：各科材料和练习入口。
- [口语与B站精选](SPEAKING-READING.md)：题目与参考回答、跟读课程、外刊精读。
- [顾家北教材说明](GUJIABEI-GUIDE.md)：页码索引和基础写作练习方式。
- [每日协作说明](AGENTS.md)：每日学习 agent 的接管和回填方式。
- [手动进度模板](PROGRESS-TEMPLATE.md)：由学习者发送完成情况，agent 整理记录。

听阅材料使用学术类。练习量按每日完成情况调整。

## 每日安排

| 模块 | 时间或数量 | 学习任务 |
| --- | --- | --- |
| 单词 | 150–200 词，新学与复习合计 | 在不背单词的雅思词汇真经中学习；选 10 个难词练拼写 |
| 口语 | 约 40 分钟 | 10 分钟提取语料，20 分钟按集数连续跟读，10 分钟回答题目 |
| 写作 | 25 分钟 | 小作文、大作文、改错轮换；先句子，再段落，逐步写整篇 |
| 听力 | 30 分钟 | 做一个小节，核对答案与文本，分析错因并回听 |
| 阅读 | 35 分钟 | 做一个专项或一篇文章，定位证据并整理少量高价值表达 |

单词和口语之外，听阅写合计约 90 分钟。时间不足时记录实际完成量，不补记未完成的任务。

影子跟读固定使用Easy English Talk，从第1集开始，每集练2–3天，学完再进入下一集。每周留一天回顾。

## 记录方式

每天发送新学数、复习数、耗时、难词和各科完成情况。每日聊天整理错题、订正和复习任务，主聊天根据记录调整后续安排。

个人学习记录保存在本地；需要发布的笔记再同步到仓库。
