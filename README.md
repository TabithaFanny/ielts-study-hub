这里集中保存雅思学习资料入口、使用说明和每日协作规则。资料核验日期为 2026-10-10；目标是寒假前的 1 月达到总分 7.0，具体考试日期待确定。

## 从这里开始

- [顾家北教材说明](GUJIABEI-GUIDE.md)：页码索引和基础写作练习方式。
- [每日协作说明](AGENTS.md)：每日学习 agent 的接管和回填方式。

当前听阅资料按学术类整理，正式考试类型尚待确认。每日安排先执行，再根据实际练习反馈调整。

## 每日安排

| 模块 | 时间或数量 | 学习任务 |
| --- | --- | --- |
| 单词 | 150–200 词，新学与复习合计 | 在不背单词的雅思词汇真经中学习；选 10 个难词练拼写 |
| 口语 | 约 40 分钟 | 10 分钟提取语料，20 分钟影子跟读，10 分钟回答题目 |
| 写作 | 25 分钟 | 小作文、大作文、改错轮换；先句子，再段落，逐步写整篇 |
| 听力 | 30 分钟 | 做一个小节，核对答案与文本，分析错因并回听 |
| 阅读 | 35 分钟 | 做一个专项或一篇文章，定位证据并整理少量高价值表达 |

单词和口语之外，听阅写合计约 90 分钟。时间不足时记录实际完成量，不补记未完成的任务。

## 记录方式

不背单词进度由学习者手动发送，使用模板中的字段。网页生词本只代表收藏的词，不代表当天全部学习内容。每日网页同步任务已取消，不自动恢复。

公开仓库当前仅保存资源链接、原创说明和空白模板。个人学习记录、生词本原始快照、截图及登录信息留在本地；以后需要公开具体笔记时，再明确选择发布内容。其他书籍、试卷、音频和参考答案保留原站链接。学习者本次明确要求上传的顾家北6.0教材作为仓库发布附件保存，具体使用见教材说明。
